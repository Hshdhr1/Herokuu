# Heroku Userbot для Minecraft (Fabric)

Продвинутый мод для Minecraft, который интегрирует функциональность Telegram юзербота, позволяя вам управлять своим аккаунтом и связывать чаты прямо из игры.

## Особенности
- **Интеграция с Telegram**: Полноценный MTProto клиент, работающий внутри Minecraft (через TDLib).
- **Команды Minecraft**: Управление юзерботом через команду `/heroku`.
- **Двойная аутентификация**: Поддержка входа через веб-интерфейс (localhost) и QR-код.
- **Связь чатов (Chat Bridge)**: Двусторонняя синхронизация между чатом Minecraft и Telegram.
- **Модульные команды**: Мощная система команд (например, `.help`, `.eval`).
- **Постоянное хранилище**: Безопасная база данных в отдельной папке `heroku/`.

## Установка
1. Установите **Fabric Loader** для Minecraft **1.21.1** (или совместимую).
2. Загрузите JAR-файл мода.
3. Поместите его в папку `.minecraft/mods`.
4. Запустите Minecraft и используйте `/heroku` для начала настройки.

## Команды
- `/heroku`: Запустить юзербот с веб-аутентификацией (localhost:8080).
- `/heroku no-web`: Запустить юзербот с аутентификацией через QR-код в консоли.
- `/heroku stop`: Остановить юзербот и веб-сервер.

## Благодарности
- Основано на оригинальном **Heroku Userbot** для Telegram.
- Работает на **Fabric API**, **TDLib**, **NanoHTTPD** и **ZXing**.
