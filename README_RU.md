# Heroku Userbot для Minecraft (Fabric)

Продвинутый мод для Minecraft, который интегрирует функциональность Telegram юзербота, позволяя вам управлять своим аккаунтом и связывать чаты прямо из игры.

## Особенности
- **Интеграция с Telegram**: Полноценный MTProto клиент, работающий внутри Minecraft.
- **Связь чатов (Chat Bridge)**: Двусторонняя синхронизация между чатом Minecraft и Telegram.
- **Модульные команды**: Мощная система команд (например, `.help`, `.eval`).
- **Постоянное хранилище**: Безопасная база данных на основе JSON для настроек и данных.

## Установка
1. Установите **Fabric Loader** для Minecraft **1.21.11**.
2. Загрузите JAR-файл мода.
3. Поместите его в папку `.minecraft/mods`.
4. Запустите Minecraft и настройте свои `api_id` и `api_hash` в файле `config/heroku.json`.

## Использование
- Используйте `.help` в Telegram или чате Minecraft, чтобы увидеть доступные команды.
- Команды начинаются с настраиваемого префикса (по умолчанию: `.`).

## Благодарности
- Основано на оригинальном **Heroku Userbot** для Telegram.
- Работает на **Fabric API** и **TDLib**.
